# Участие в разработке

## Локальный запуск

Для приложения, CLI и основных тестов достаточно Node.js 18+; рекомендуется Node.js 24 LTS.
Установка npm-зависимостей и сборка не требуются.

```bash
npm start
npm test
node bin/tg2md.js examples/sample-result.json -o output
```

`npm start` занимает терминал до остановки через `Ctrl+C`; остальные команды выполняйте в другом терминале.

## Устройство проекта

- `src/core.js` преобразует экспорт в документы и статистику, не выполняя ввод-вывод.
- `src/zip.js` создаёт ZIP из списка документов.
- Оба модуля используются через `require` в Node.js и через глобальные объекты в браузере.
- `public/app.js` отвечает за DOM, выбор файла, настройки, локализацию и скачивание.
- `src/i18n.js` содержит одинаковый набор ключей для `ru`, `en` и `uk`.
- `server.js` раздаёт только файлы из `public/` и `src/`.
- `bin/tg2md.js` связывает файловую систему с ядром конвертации.

Сохраняйте совместимость общих модулей с обоими окружениями и возможность офлайн-запуска.
Придерживайтесь существующего стиля: два пробела в JavaScript, четыре в Python, UTF-8 и окончания строк LF.
При изменении пользовательских команд обновляйте обе версии README.

## Проверки

### Основные тесты

```bash
npm test
```

Используется встроенный `node:test`. Для исправления ошибки добавляйте небольшой регрессионный пример,
проверяющий поведение на входном экспорте. Демонстрационные данные находятся в `examples/`,
общие тестовые данные — в `test/helpers/fixture.js`.

### Браузерная проверка

Дополнительно установите Python 3.10+ с pip. При желании используйте виртуальное окружение `.venv`.

```bash
python -m pip install -r scripts/requirements-ui.txt
python -m playwright install chromium
python scripts/ui-check.py
```

На Linux для установки системных библиотек Chromium можно использовать:

```bash
python -m playwright install --with-deps chromium
```

Тест сам запускает локальный Node.js-сервер и останавливает его после завершения, в том числе при ошибке.
Проверяются языки, темы, ошибки, конвертация и скачивание ZIP. Результаты записываются в `.tmp-ui-check/`,
которая исключена из Git.

Настройки через переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `NODE_BINARY` | Путь к Node.js, если команда `node` недоступна в `PATH` |
| `UI_PORT` | Порт тестового сервера; по умолчанию `5177` |
| `UI_OUTPUT_DIR` | Каталог результатов; по умолчанию `.tmp-ui-check` в корне проекта |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` | Путь к собственному Chromium-совместимому браузеру вместо версии Playwright |

В GitHub Actions основные тесты выполняются на Windows и Linux с Node.js 18, 22 и 24.
Браузерная проверка выполняется отдельно на Ubuntu с Node.js 24 и Python 3.13.

## Сообщения об ошибках и изменения

В Issue укажите версию Node.js или браузера, ОС, способ запуска, шаги воспроизведения,
ожидаемый и фактический результат. Для воспроизведения используйте небольшой синтетический JSON,
аналогичный `examples/sample-result.json`.

В Pull Request кратко опишите изменения и выполненные проверки. Если меняется интерфейс,
приложите актуальный скриншот. Для новых подписей добавьте переводы во все три словаря.
